# Software Engineer, AI Applications (Early Career)
Northwind Analytics — Jersey City, NJ (Hybrid) — Full-time
Apply via Greenhouse

## About the role
Northwind builds document-intelligence products for infrastructure and construction clients. You will join a six-person applied AI team shipping LLM-powered features into a production web platform used by state agencies and engineering firms.

## What you'll do
- Design and build backend services in Python (FastAPI) that orchestrate large language model (LLM) workflows, including retrieval-augmented generation (RAG) over large document corpora.
- Build and maintain evaluation pipelines that measure LLM output quality, grounding, and regression across releases.
- Develop React and TypeScript front-end features that surface model results to non-technical users.
- Own CI/CD: automate testing and deployment with GitHub Actions and Docker; deploy to Azure or AWS.
- Model and query relational data in PostgreSQL, including vector search with pgvector.
- Collaborate with product managers and domain experts to translate compliance requirements into features.

## Requirements
- Bachelor's degree in Computer Science or related field (Master's a plus); graduating by June 2027 or within two years of graduation.
- Strong Python skills and experience building REST APIs (FastAPI, Flask, or Django).
- Hands-on experience with LLM APIs (OpenAI, Anthropic, or similar) and RAG architectures, including embeddings and vector databases.
- Experience with React, TypeScript, and modern JavaScript.
- Working knowledge of PostgreSQL and SQL.
- Experience with Git, GitHub Actions (or similar CI/CD), and Docker.
- Solid grasp of software testing: unit tests, integration tests, and test automation.
- Clear written and verbal communication.

## Nice to have
- LangChain, LlamaIndex, or similar orchestration frameworks.
- Knowledge-graph or graph-database experience (Neo4j, Cypher).
- Kubernetes or infrastructure-as-code (Terraform).
- Prompt engineering and structured-output techniques.
- Experience with agile development and code review.
- Azure App Service or AWS Lambda deployment experience.
